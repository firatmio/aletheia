# Aletheia brand

## Mark

**ἀ** is the first letter of ἀλήθεια ("un-forgetting"). The small breathing mark above the alpha carries the verified green: it is the one part of the mark that says "checked", like `[ok]` in recall output.

| File | Use |
|---|---|
| `assets/brand/aletheia-lockup.svg` / `-dark.svg` | Mark and wordmark: README header, landing page, docs |
| `assets/brand/aletheia-mark.svg` | Mark in color on light backgrounds |
| `assets/brand/aletheia-mark-dark.svg` | Mark on dark backgrounds |
| `assets/brand/aletheia-mark-mono.svg` | One-color contexts (print, stamps, single-ink) |
| `assets/brand/aletheia-mark-adaptive.svg` | Follows the viewer's light or dark preference |
| `assets/brand/favicon.svg` | Favicon and app icon: the mark on an ink tile |
| `plugin/.claude-plugin/icon.png` | Claude plugin directory icon: `favicon.svg` with square corners, 1024×1024 PNG (the directory takes no SVG and rounds corners itself) |

## Color

| Token | Light | Dark | Role |
|---|---|---|---|
| Ink | `#142033` | `#e5eaf1` | Text, the alpha |
| Paper | `#f4f6f7` | `#0b111b` | Page |
| Verified | `#0f7a5a` | `#3fc69a` | `[ok]`, anchors that hold, the breathing mark |
| Stale | `#a85f00` | `#e3a14a` | Evidence that broke |
| Code | `#0f1724` | `#070b12` | Terminal and code panels |

Color always carries meaning; it is never decoration.

## Type

- **Display:** Newsreader (italic for the wordmark).
- **Body:** IBM Plex Sans.
- **Code:** IBM Plex Mono.

All three are on Google Fonts under the SIL Open Font License.

## How the files were made

The mark and the lockup are plain SVG paths, so they render the same everywhere without fonts.

- The alpha and its breathing mark come from **Noto Serif Medium**, using the font's own composition of U+1F00 (alpha plus U+1FBF, shifted right). They are kept as two paths so the breathing mark can take its own color.
- The wordmark is **Newsreader Italic** at weight 400 and optical size 48, set without kerning.

The glyphs were converted with [fontTools](https://github.com/fonttools/fonttools) (`SVGPathPen`, `varLib.instancer`) in a throwaway virtualenv. fontTools is not a project dependency. Both fonts are licensed under the SIL Open Font License 1.1, which allows using their outlines in a logo.

The "how it works" diagram (`assets/how-it-works-*.svg`) is generated by `scripts/gen_assets.py`, which uses only the Python standard library.

## Imagery

Imagery comes from the product itself: claim ↔ evidence, real recall output, the real terminal. There is no mascot, and stock photos or generated images are not used.

The one exception is public-domain art behind the landing page's hero. That is Pierre Puvis de Chavannes, *The Sacred Grove, Beloved of the Arts and the Muses* (1884–89, Art Institute of Chicago), from Wikimedia Commons.
- **How it is shown:** in gray, softened, fading down into the page. A small lens around the pointer shows it in color.
- **Credit:** the footer credits it.
- **Files:** `site/public/sacred-grove.webp` (gray) and `sacred-grove-color.webp`, both 1600 px wide with a 2.5 px Gaussian blur, made with Pillow from the Commons original. Earlier explorations are kept for reference in `image-prompts.md` and `photo-candidates.md`.
