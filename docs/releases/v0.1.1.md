The binary behaves exactly as in 0.1.0. This release is packaging: it gets Aletheia into two more directories and fixes the Homebrew cask on Linux.

- **npm:** `@firatmio/aletheia` declares `mcpName: io.github.firatmio/aletheia`, so it can be listed in the official MCP Registry.
- **Claude Code plugin 0.1.1:** it now has a README that lists everything the plugin runs and reads, an icon, and links to documentation, support, the privacy policy and the license. These are what Anthropic's plugin directory needs. Update with `claude plugin update aletheia@aletheia`.
- **Homebrew:** `brew install --cask firatmio/tap/aletheia` no longer fails on Linux. The quarantine fix for the unsigned binary now runs on macOS only.
- **Reproducible archives:** the archives take their file times from the commit, so rebuilding a tag gives the same files.
- **Privacy:** the policy is at https://aletheia.firattunaarslan.me/privacy. Aletheia collects nothing and makes no network requests.

Install or upgrade: `npm install -g @firatmio/aletheia`, `go install github.com/firatmio/aletheia/cmd/aletheia@latest`, `scoop update aletheia` or `brew upgrade --cask aletheia`.
