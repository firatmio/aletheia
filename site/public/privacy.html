Privacy

Updated 24 October 2026

Aletheia collects nothing. It has no telemetry and makes no network requests. Your memories stay in your project, on your machine.

The software

This covers the aletheia binary, its MCP server, the Claude Code plugin, and the npm, Scoop and Homebrew packages that install it.

  • Memories are Markdown files in your project's .aletheia/ folder. You decide whether to commit and share them.
  • To check memories against the code, Aletheia reads your project's files. It never reads outside the project root, and anchors never execute anything.
  • With the Claude Code hooks, it reads the prompt you send and, when a task ends, the session transcript file that Claude Code names, to record which files the task changed. Both stay on your machine.
  • The one program it starts is git check-ignore, during aletheia init.
  • Downloading it through npm, GitHub, Scoop or Homebrew is covered by those services' own policies.

This website

  • The site is a set of static pages with no analytics, no cookies and no tracking. Its fonts and images are served from this site, so your browser makes no requests to third parties.
  • It is hosted by Vercel, which processes standard request data such as IP address and user agent to serve and protect the site, under Vercel's privacy policy.
  • The site keeps two preferences in your browser's local storage: the colour theme and the install tab you picked. They never leave your browser.
